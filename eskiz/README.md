# Эскиз — быстрый расчёт мебели

Клиент звонит → мастер выбирает «что делаем», вписывает размеры, материал и класс
фурнитуры → сразу видит цену и картинку → отправляет клиенту предложение
в Viber/Telegram или PDF → по кнопке «Для цеха» получает файлы для порезки в ВіЯр.

Версия 0.9 — переделка прототипа 0.8:
- **отвязано от OpenAI**: нет входа через ChatGPT, хостинга Sites и ключей OpenAI;
- **без технических знаний**: секции, полки, планки, петли, ножки подбираются сами;
- **считает деньги**: листы, кромка, порезка, фасады, фурнитура, работа, наценка,
  доставка и монтаж — по прайсу мастера («Настройки» ⚙);
- работает в браузере на телефоне и компьютере, ставится на телефон как приложение (PWA),
  работает без интернета. Расчёты пока хранятся на самом устройстве.

## Запуск

Нужен Node.js 20+.

```sh
cd eskiz
npm install
npm run dev      # http://localhost:5173
npm test         # проверки расчётов
npm run build    # готовый сайт в папке dist/
```

## Публикация (бесплатно)

Сайт статический — подходит Cloudflare Pages, Netlify или GitHub Pages.
Cloudflare Pages: подключить этот репозиторий, корневая папка `eskiz`,
команда сборки `npm run build`, папка результата `dist`. Свой домен — в настройках проекта.

## Как устроено

| Папка | Что внутри |
|---|---|
| `src/engine/order.ts` | Простой заказ клиента → корпуса (секции, полки, деление кухни на модули) |
| `src/engine/pricing.ts` | Цена: листы, кромка, фасады, фурнитура по классам, работа, наценка |
| `src/engine/furniture.ts`, `kitchen.ts`, `sliding.ts`, `viyar-export.ts`, `materials.ts` | Деталировка, купе ADS BRAND, экспорт ВіЯр — перенесены из версии 0.8 без изменений |
| `src/ui/` | Экраны: расчёт, предложение клиенту, для цеха, настройки, 3D-картинка |
| `src/storage.ts` | Хранение на устройстве (позже — облако) |
| `tests/` | Проверки расчётов |

Правила подбора (меняются в коде `pricing.ts` / `order.ts`):
- петли по высоте двери: до 900 мм — 2, до 1600 — 3, до 2000 — 4, выше — 5;
- шкаф шире 2400 мм делится на несколько корпусов; двери не шире ~600 мм;
- купе: до 2400 мм — 2 двери, шире — 3;
- кухня делится на модули до 600 мм, мойка 800 мм, пеналы 600 мм, верх — над низом без пеналов;
- листы = площадь деталей ÷ (площадь листа × полезный выход, по умолчанию 80 %).

Цены по умолчанию — ориентировочные. Перед работой впишите свои в «Настройках».

## Чего пока нет (следующие этапы)

1. Кухня полностью: ящики и направляющие, угловые модули, вырезы под мойку и варочную, разные фасады.
2. Вход и облако: один аккаунт на телефоне и компьютере, общий доступ для сотрудников.
3. Расчёт по фото или PDF: AI читает эскиз и заполняет размеры (ключ — на сервере, не у пользователя).
4. Цех: экспорт KRONAS, проверенный импорт ВіЯр, шаблоны присадки (петли, конфирматы).
5. Кабинет клиента: ссылка для клиента — статус заказа, фото из цеха, сроки, оплаты, уведомления.
6. Приложение в Google Play / App Store (обёртка того же кода).
