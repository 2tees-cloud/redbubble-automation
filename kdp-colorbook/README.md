# KDP Coloring Books — автопилот раскрасок для Amazon KDP

Одна книга в день без участия человека: **исследование ниши → страницы → проверка качества →
интерьер и обложка → метаданные → загрузка в KDP**. Бесплатные AI-провайдеры с автопереключением.

## Автопилот: настройка один раз
1. `pip install -r requirements.txt` и установленный Google Chrome (или `playwright install chromium`
   и `kdp.channel: ""` в `config.yaml`).
2. `cp .env.example .env` — ключи: хотя бы Gemini (текст + vision) и Cloudflare (картинки);
   `NTFY_TOPIC` — уведомления на телефон (приложение ntfy).
3. В `config.yaml`: `autopilot.author` — имя автора/псевдоним.
4. `python scripts/kdp_login.py` — войти в KDP вручную один раз (с кодом 2FA); сессия сохранится.
5. `python scripts/research.py` — посмотреть, какие ниши находит исследование.
6. `python scripts/daily.py` — первая книга. **Она сохранится черновиком**: откройте её в KDP,
   проверьте, что робот всё заполнил верно, и нажмите Publish. Дальше книги публикуются сами.
7. `python scripts/schedule.py --time 09:15` — запуск каждый день (Windows: Планировщик; macOS/Linux: cron).

`python scripts/daily.py --status` — последние запуски. Незаконченная книга (кончились лимиты API,
нужен вход в KDP) доделывается при следующем запуске раньше новой.

### Что делает автопилот
- **Исследование** (`core/research.py`): подсказки поиска Amazon (что реально ищут) по базовым фразам,
  раскрутке по алфавиту, праздникам через 30–75 дней и идеям LLM; конкуренция — выдача Amazon (число книг,
  отзывы топ-10) и BSR лидеров (бесплатно; при капче — оценка по подсказкам) или Keepa (`KEEPA_API_KEY`).
  Лучшие — «окна»: в топе есть книги с < 50 отзывов, которые продаются. Похожие на ниши последних
  60 дней пропускаются. Отчёт — `data/research/<дата>.json`.
- **Безопасность** (`core/safety.py`): бренды и персонажи (Disney, Pokémon, Bluey…), знаменитости,
  взрослый/жестокий/политический контент — стоп-лист + LLM-модерация темы, сюжетов и метаданных.
  Модерация недоступна → тема отклоняется. Это главная защита аккаунта от бана за нарушение прав.
- **Аудитория** (`core/profiles.py`): детские (простые, толстые линии) и взрослые раскраски (детальные
  узоры, мандалы) — свои промпты, пороги фильтра брака и тексты листинга; форматы 8.5×11, 8.5×8.5,
  8.25×8.25, 8×10, 8.25×11, 6×9.
- **KDP-робот** (`core/kdp.py`): Details → Content → Pricing → Publish в настоящем браузере; бесплатный ISBN,
  ч/б печать, формат, загрузка PDF, раскрытие AI-контента, превьюер, цена не ниже минимума KDP.
  Прогресс по шагам — `kdp_state.json` в папке книги; при сбое — скриншот и HTML в `kdp_debug/`.

### Риски — прочитать
- **Условия Amazon запрещают роботов.** За автоматизацию KDP может закрыть аккаунт вместе с роялти.
  Снижают риск: свой компьютер и обычный Chrome, видимое окно, одна книга в день, паузы, вход вручную.
- **Вёрстка KDP меняется.** Селекторы — в `kdp_selectors.yaml`; если шаг падает, придёт уведомление,
  а в `kdp_debug/` будут скриншот и HTML — по ним дописывается новый вариант селектора, код не трогается.
  Первый запуск (черновиком) нужен именно для проверки селекторов.
- **Категории KDP** выбираются по путям из `kdp.categories` — сверьте их с окном «Choose categories».
- **Качество.** Фильтр брака отсекает плохие страницы, но KDP снимает книги за «low content / poor quality».
  Раз в неделю просматривайте `out/` и `cover_preview.png`.

## AI-роутер

Два роутера с автопереключением: **текст** (Gemini, Groq, Cerebras, Z.AI, Mistral, OpenRouter, xAI)
и **картинки** (Cloudflare FLUX → HuggingFace → Pollinations). Порядок в `config.yaml` = приоритет.

Если провайдер упал, он встаёт на паузу, а запрос уходит к следующему:
- 429 (лимит) → пауза по Retry-After или 1 мин, растёт ×2 при повторах (до 12 ч)
- 401/403 (плохой ключ) → 24 ч
- 5xx / таймаут → 30 с и растёт
- 200, но мусор (не JSON, не картинка, маленькая картинка) → тоже переход дальше

Паузы и расход за день хранятся в `data/router_state.db` и переживают перезапуск.

## Постобработка и PDF для KDP
Генератор выдаёт ~1024×1024 с серыми тенями и мусором, а KDP нужно 300 DPI (8.5×11" = 2550×3300 px).
Растягивать картинку бесполезно, поэтому страница векторизуется:
```
картинка → серый → порог (Otsu, тени светлее 200 уходят в белое) → удаление точек и дырок
        → potrace (кривые Безье) → PDF: линии чёткие при любом разрешении
```
Интерьер собирается собственным PDF-писателем: в файле нет шрифтов вообще (reportlab добавляет
невстроенный Helvetica, из-за чего KDP может отклонить файл). Поля у корешка берутся из таблицы KDP
по числу страниц, картинки идут только на правых страницах, обороты пустые, число страниц чётное.
Настройки — секции `postprocess` и `book` в `config.yaml`.

## Фильтр брака и конвейер
Каждая страница проходит проверки от дешёвых к дорогим (`core/quality.py`, пороги — `quality` в `config.yaml`):
1. **Пиксели** — доля линий, сплошные чёрные заливки, число областей для раскраски, слишком мелкие ячейки, линии на краю.
2. **Дубликаты** — перцептивный хеш против уже принятых страниц.
3. **Vision** — модель с `vision_model` в конфиге смотрит на картинку: текст/водяной знак, лишние пальцы и лапы,
   обрезанный объект, тени, соответствие сюжету, оценка 1–10. Пауза vision не блокирует обычный текст.

`scripts/make_pages.py` связывает всё: тема → сюжеты (текстовый роутер) → генерация → чистка → фильтр.
Брак с причинами — в `rejected/` и `manifest.json`. Манифест пишется после каждой страницы: если бесплатные лимиты
кончились, та же команда позже продолжит с места остановки.

## От темы до загрузки в KDP — 3 команды
```bash
python scripts/make_pages.py "dinosaurs" -n 30 --pdf        # страницы + фильтр брака + interior.pdf
# просмотреть out/dinosaurs/pages, лишнее удалить из manifest.json → пересобрать --pdf
python scripts/make_cover.py out/dinosaurs --author "Имя"  # cover.pdf + metadata.txt
```
В KDP загружаются `interior.pdf` и `cover.pdf`; текст для формы — из `metadata.txt`.
При публикации отметьте, что иллюстрации созданы ИИ (AI-generated content) — это обязательно.

## Обложка и метаданные
- **Размер** по формуле KDP: bleed 0.125" + задник + корешок (страницы × 0.002252" для белой бумаги,
  0.0025" для кремовой) + лицо + bleed. Страница PDF задаётся в пунктах — точно, без округления пикселей.
- **Лицо** — лучшая по оценке vision страница книги, раскрашенная программно палитрой (`--palette`, `--seed`):
  чётко при 300 DPI и честно показывает содержимое. **Задник** — описание и 4 превью страниц.
- **Место под штрихкод** (2×1.2" справа внизу задника) остаётся пустым. **Текст на корешке** — только от 79 страниц
  (правило KDP), читается сверху вниз.
- Весь текст нарисован в картинку, в PDF нет шрифтов. Шрифт — Fredoka (OFL, `assets/fonts`), только латиница.
- `cover_preview.png` — превью с разметкой: красный — обрез, синий — корешок, зелёный — безопасная зона,
  оранжевый — штрихкод.
- **Метаданные**: модель пишет название, подзаголовок, описание, 7 ключевых фраз, категории и текст задника;
  код проверяет правила KDP (≤50 символов на фразу, без «bestseller/free/Amazon/Kindle», разрешённый HTML,
  ≤4000 символов описания). Что нельзя исправить автоматически — в разделе «ПРОВЕРИТЬ ВРУЧНУЮ».

## Запуск
```bash
pip install -r requirements.txt
cp .env.example .env        # вписать ключи
python tests/test_fallback.py          # офлайн-тесты логики
python scripts/check_router.py --models  # какие модели доступны по вашим ключам
python scripts/check_router.py           # живой тест: JSON с темами + 1 страница раскраски в out/
python scripts/check_router.py --status  # кто на паузе, сколько запросов сегодня
python tests/test_postprocess.py         # офлайн-тесты постобработки и PDF
python tests/test_quality.py             # офлайн-тесты фильтра брака и конвейера
python tests/test_cover.py               # офлайн-тесты обложки и метаданных
python tests/test_profiles_safety.py     # аудитория, форматы, фильтр опасных тем
python tests/test_research.py            # исследование ниш (фикстуры HTML Amazon)
python tests/test_kdp.py                 # KDP-робот на локальном макете (нужен playwright + Chromium)
python tests/test_autopilot.py           # автопилот целиком, всё внешнее подменено
python scripts/make_pages.py "dinosaurs" -n 30 --pdf   # тема → out/dinosaurs/{pages,rejected,interior.pdf}
python scripts/build_interior.py out/pages --svg   # папка картинок → out/interior.pdf (+ чистые SVG)
```

## Использование в коде
```python
from core import load_routers
text, image = load_routers()
themes = text.chat_json("3 темы раскрасок для 4-8 лет, JSON")["data"]
page = image.generate("coloring page, cute dinosaur, thick black outlines, white background")
page["image"].save("page.png")

from core import book, postprocess
vec = postprocess.process(page["image"])            # чистый вектор
book.build_interior([vec, ...], "out/interior.pdf")  # PDF-интерьер для KDP
```
Добавить провайдера — новая запись в `config.yaml` + ключ в `.env`, код трогать не нужно.
